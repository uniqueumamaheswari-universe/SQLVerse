# 🗄️ SQLVerse Foundation 

## 📌 Purpose

This repository contains the foundational philosophy, business universes, learning assets, and reusable frameworks that power the **SQLVerse Business Multiverse**.

---

## 🧭 Repository Philosophy

The repository is organised around three principles:

- **Separation of Concerns** — Philosophy, learning assets, and reusable frameworks live in distinct folders.
- **Single Source of Truth** — Every artifact lives in exactly one place.
- **Scalability** — The repository is designed to grow.

---

## 📂 Repository Evolution Strategy

The repository is designed to grow. New top-level folders may be added without restructuring:

- `skill-tree/` — The Skill‑Tree database and extraction workflows
- `characters/` — SQLVerse characters and their scenarios
- `templates/` — Project templates, report templates, query templates

When a new top-level folder is added, only the Repository Standards document needs to be updated—the Manifesto, the Guide, and the README remain stable.

## 🚀 Getting Started

Begin your journey through the SQLVerse in four steps:

1. **Start with the [Business Suite Guide](core/00-SQLVerse-Business-Suite-Guide.md).**  
   It greets and guides you — welcoming you to the multiverse and showing you how to navigate the universes.

2. **Read the [Manifesto](core/SQLVERSE_BUSINESS_MULTIVERSE.md).**  
   It explains the SQLVerse ideology — the philosophy, principles, and laws that govern every business world.

3. **Explore the Business Universes.**  
   Dive into the data models — `resources/data-models/flagship-universes/` — where you will encounter the four flagship worlds: E‑Store, Hospital Planet, Real Estate Planet, and FinVERSE.

4. **Contributing or extending SQLVerse? Refer to the [Repository Standards](docs/Repository-Standards.md).**  
   It is the authoritative reference — defining naming conventions, versioning, and how the repository evolves.
